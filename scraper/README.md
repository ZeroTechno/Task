# The Polite Scraper

## Target Classification
* **Target Site:** Books to Scrape (`https://books.toscrape.com/`)
* **Purpose:** Public sandbox built specifically for web scraping practice.
* **Scope:** First 3 catalogue pages (60 books total).
* **Data Collected:** Book title, product URL, raw price, numeric price (GBP), availability, rating, description, source page, and fetched timestamp.
* **Robots.txt Check:** `https://books.toscrape.com/robots.txt` returned 404 (no robots file found).
* **Ethics Declaration:** I will not reuse this code on another site without checking its rules and terms first.
